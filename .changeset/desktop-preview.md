A preview of your dev server. Preview in the right panel opens the page beside the thread: the servers running in the
project's terminals, the dev scripts of package.json to start one, or an address you type. Point at the page (⇧⌘C):
a click picks an element, a drag picks an area, and each goes into the composer as a chip. The agent gets what you
picked with the components it is in when the page is React or Vue in development, its selector, text, styles and HTML,
and a screenshot of it. The core finds the local addresses a terminal prints, and lists the scripts that start a server.
