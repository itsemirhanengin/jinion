## Requirements

| What        | Needed                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------- |
| Node.js     | 22 or later                                                                               |
| System      | macOS or Linux                                                                            |
| Account     | A Claude account on a subscription, such as Pro or Max                                    |
| Terminal    | Any modern terminal; see [recommended terminals](#recommended-terminals) for the best fit |

## Install

```npm
npm i -g @jinion/cli
```

Check that it worked:

```sh
jinion --version
```

It prints the version, such as `0.1.0`. If your shell says `command not found`, see
[Troubleshooting](/reference/troubleshooting#jinion-command-not-found).

## Sign in

Start Jinion in any project:

```sh
cd ~/code/my-project
jinion
```

If you have signed in to Claude on this machine before, the banner shows the account and you're done. If not, type
`/account`, go to the account that says "Not signed in" and press `enter`. Jinion opens the sign-in in your browser;
paste the code the browser shows.

When a login expires, sign it in again from the same panel; see [Sign in again](/models-and-accounts#sign-in-again).
To use more than one account, see [Switch models and accounts](/models-and-accounts#switch-accounts).

## Try it without a model

`jinion --demo` plays a scripted session: questions, edits, test runs and background tasks, without sending anything
to a model. It is a quick way to look around.

```sh
jinion --demo
```

Type `add rate limiting to the api` for the full tour, or `hello` for a short one.

## Update

```npm
npm i -g @jinion/cli@latest
```

Restart running sessions to pick up the new version. Your conversations and settings stay.

## Uninstall

```npm
npm rm -g @jinion/cli
```

Jinion's data stays in `~/.jinion`. Delete that folder to remove your conversations, memory and settings too. If you
added accounts with `/account`, [remove them](/models-and-accounts#remove-an-account) first, so they are signed out.
See [The ~/.jinion folder](/reference/jinion-folder).

## Recommended terminals

Jinion runs in any terminal that supports colors and the mouse. These also show desktop notifications and report
focus, so Jinion only notifies you when you're looking elsewhere:

| Terminal | Notifications |
| -------- | ------------- |
| Ghostty  | Yes           |
| iTerm2   | Yes           |
| kitty    | Yes           |
| WezTerm  | Yes           |
| Warp     | Yes           |
| foot     | Yes           |

Inside tmux or screen, and in other terminals, Jinion rings the bell instead. See
[Set up your terminal](/terminal-setup).
