The context is everything the model reads before it answers: the system prompt, your project's instructions, the
tools, and the whole conversation so far. It has a limit, the context window. A long conversation fills it.

## Compact a long conversation

A long conversation fills the model's context. `/compact` summarizes it so far and carries on from the summary. Name
what matters most and it is kept above all:

```text
/compact the API changes
```

Jinion also compacts on its own as the context fills. When a fifth or less is left, the rule under the prompt says how
much. After compacting, the conversation marks where, such as `[x] Compacted · 160.2k → 21.4k tokens`. Click it
to see the summary.
