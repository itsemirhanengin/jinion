Every edit the agent makes shows as a diff in the conversation. To look at everything together, type `/diff`.

## See what isn't committed

`/diff` opens full screen. Its Current view lists every file that isn't committed, staged or not, new files included,
with the lines added and removed. Files the agent changed in this conversation are marked `agent`, so they stand apart
from your own edits.

```terminal
{accent|+------------------------------------------------------------------------------------------+}

```

When nothing is uncommitted, Current shows what your branch adds on top of the default branch.

## Go turn by turn

`left` and `right` step through the turns in which the agent changed files, newest first. Each turn shows only that
turn's edits, so you can see what a single request did.

<Callout>
  Turn views come from the agent's own edits. A change made by a command shows only under Current.
</Callout>

## Several repositories in one folder

You can start Jinion in a folder that holds several repositories, for context across them. Jinion finds the
repositories up to three folders down, and:

- `/diff` groups the changes under each repository, with its branch;
- the status line's git segment sums them up, such as `4 repos *7`;
- the agent runs git in the repository a change belongs to.

## Take a change back

To undo what the agent did, [rewind](/conversations#rewind-to-an-earlier-message) to before the message that caused it.
