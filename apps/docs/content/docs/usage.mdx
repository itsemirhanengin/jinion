## See your limits

`/usage` opens full screen with three parts:

- **Plan limits**: the 5-hour window and the week, per model where your plan has one, with when each resets.
- **This session**: its cost at API prices, time spent, lines changed, and tokens by model.
- **What adds to your limits**: over the last day or week (`d` and `w`), the kinds of sessions and the skills,
  subagents and MCP servers that used the most.

<Callout>
  The cost is what the session would cost at API prices. A subscription doesn't bill it; it shows how much you used.
</Callout>

## See every day of use

Press `tab` in `/usage`, or type `/stats`, for a calendar of every day you used it, a square per day, shaded by how
much you did, like GitHub's contribution graph.

| Key            | Does                                                   |
| -------------- | ------------------------------------------------------ |
| Arrow keys     | Pick a day to see its numbers                          |
| `r`            | Switch between all time, the last 30 days and the last 7 |

Below the calendar: sessions, active days, streaks, your busiest day, your longest session, and each model's share.

The stats come from the Claude Code transcripts on this machine, so they cover Claude Code used outside Jinion too.

## Keep an eye on it while you work

The [status line](/status-line) can show the plan limits (`5h 8% · 7d 20%`), the context (`ctx [====------] 41%`)
and the session's cost all the time.
