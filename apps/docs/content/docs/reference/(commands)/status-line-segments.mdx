---
title: Status line segments
description: Every segment the status line can show, with an example and its styles.
---

Choose which ones show with `/statusline`. See [Customize the status line](/status-line).

| Segment      | Shows                                                       | Styles                                        |
| ------------ | ----------------------------------------------------------- | --------------------------------------------- |
| Jinion       | `jinion`                                                    |                                               |
| Model        | `[M] Opus 5.5 · high`                                       | with effort, name only                        |
| Account      | `[A] me@example.com · Max`, or `[A] work`                   | organization or email, and plan; account name |
| Mode         | `Auto`                                                      |                                               |
| Directory    | `[D] code/api`                                              | last two folders, full path, folder name      |
| Worktree     | `[W] swift-running-fox`, in a conversation with a [worktree](/worktrees) |                     |
| Git          | `[G] main *3 ↑1`, or `[G] 4 repos *7` in a folder of several | with changes and commits ahead or behind, branch only |
| Context      | `ctx [====------] 41%`                                      | tokens, percent, meter                        |
| Plan limits  | `5h 92% left · 7d 80% left`, what is left of each window    | 5h and 7d, 5h with reset time, 7d, 5h meter   |
| Cost         | `$0.12`, at API prices                                      |                                               |
| Changes      | `+42 -7` lines in this conversation                         |                                               |
| Tasks        | `tasks 2/5`                                                 |                                               |
| Title        | What the conversation is about: the title Jinion gives it, or the one set with `/rename` |                  |
| Duration     | How long ago the conversation started                       |                                               |
| Turns        | `3 turns`, the prompts you sent                             |                                               |
| Clock        | The time of day                                             |                                               |
| Agent        | The agent in use                                            |                                               |
| Version      | `v0.1.0`                                                    |                                               |
