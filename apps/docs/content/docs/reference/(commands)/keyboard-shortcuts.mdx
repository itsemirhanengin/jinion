---
title: Keyboard shortcuts
description: Every key Jinion responds to, in the prompt, in panels and in the conversation.
---

`/help` shows these in a session too.

## Prompt

| Key                                      | Does                                                    |
| ---------------------------------------- | ------------------------------------------------------- |
| `enter`                                  | Sends the message; while the agent works, steers it     |
| `ctrl+q`                                 | While the agent works, queues the message for after the turn |
| `shift+enter`, `alt+enter`, trailing `\` | New line                                                |
| `up` / `down`                            | Goes through the messages you sent                      |
| `/`                                      | Opens the command list                                  |
| `$`                                      | Picks a skill or MCP prompt                             |
| `@`                                      | Mentions a file or folder                               |
| `ctrl+v`                                 | Attaches the image on the clipboard                     |

## Editing

| Key                                                  | Does                        |
| ---------------------------------------------------- | --------------------------- |
| `ctrl+a` / `ctrl+e`, `home` / `end`                  | Start or end of the line    |
| `alt+left` / `alt+right`, `ctrl+left` / `ctrl+right`, `alt+b` / `alt+f` | Moves by word |
| `ctrl+w`, `alt+backspace`                            | Deletes the word before     |
| `ctrl+u` / `ctrl+k`                                  | Deletes to the start or end |

## While the agent works

| Key       | Does                                                         |
| --------- | ------------------------------------------------------------ |
| `esc`     | Interrupts the turn                                          |
| `ctrl+b`  | Sends the running command or subagent to the background      |
| `ctrl+t`  | Opens the background tasks                                   |
| `ctrl+o`  | Expands or collapses all long output, thinking and pasted text |

## Conversation

| Key                          | Does                                                                 |
| ---------------------------- | -------------------------------------------------------------------- |
| `esc` `esc`                  | Rewinds to before an earlier message; with text in the prompt, clears it first |
| `shift+tab`                  | Switches the permission mode                                         |
| `ctrl+g`                     | Turns [worktrees](/worktrees) on or off for new conversations        |
| `ctrl+n`                     | Starts a new conversation in a [tab](/conversations/tabs)            |
| `alt+1..9`                   | Goes to that tab; on macOS, Option has to send Meta (see [Tabs](/conversations/tabs)) |
| `ctrl+s`                     | Hides or shows the column of [tabs](/conversations/tabs)             |
| Mouse wheel, `pgup` / `pgdn` | Scrolls the conversation                                             |
| Click                        | Expands or collapses what lights up under the pointer: output, thinking, a subagent, a long edit |
| Drag                         | Selects text and copies it when you let go                           |
| Double-click, triple-click   | Selects a word (a path or a URL as one), or a line, and copies it    |
| `ctrl+c` with text selected  | Copies it again, rather than interrupting or quitting                |
| `shift` + drag               | Your terminal's own selection (`option` in iTerm2, `fn` in Terminal.app) |
| `ctrl+c`                     | Interrupts, closes a panel, clears the prompt, or quits              |

## Panels

Panels such as `/model`, `/resume` or a question share the same keys:

| Key              | Does                                            |
| ---------------- | ----------------------------------------------- |
| `up` / `down`    | Moves                                           |
| `enter`          | Picks                                           |
| `space`          | Checks an option, where you can pick several    |
| `n`              | Adds a note to the option you're on             |
| `left` / `right` | Switches tabs, or the effort in `/model`        |
| `shift+up` / `shift+down`, wheel | Scrolls a long command in a permission question |
| `l`              | Signs the account in again, in `/account`       |
| `d`              | Removes the account, in `/account`; press it twice |
| `esc`            | Closes, or cancels the question                 |
