---
title: The ~/.jinion folder
description: Where Jinion keeps its settings, conversations, memory, accounts and logs.
---

Jinion keeps everything on your machine, in `~/.jinion`. Set `JINION_HOME` to use another folder.

```text
~/.jinion/
|-- settings.json          the last model and account, the status line, servers turned off
|-- limits.json            the plan limits last seen, per account
|-- mcp.json               MCP servers of Jinion's own
|-- memory/                user notes, one Markdown file each
|-- accounts/              logins added with /account
|-- plugins/               skills handed to the agent
|-- usage/                 what /stats has read so far
|-- logs/                  debug logs from --debug
'-- projects/
    '-- -Users-me-code-api/
        |-- settings.json      the mode, and the .mcp.json servers turned on
        |-- permissions.json   the "don't ask again" rules
        |-- memory/            project notes
        '-- sessions/          one JSON file per conversation
```

A project's folder is named after its path, with every character other than letters and digits turned into `-`.

## Files

| Path                               | What it holds                                                                          |
| ---------------------------------- | -------------------------------------------------------------------------------------- |
| `settings.json`                    | The model and account you picked last, the status line, and MCP servers you turned off |
| `limits.json`                      | Each account's plan limits when it was last used, shown in `/account`                  |
| `mcp.json`                         | MCP servers only Jinion uses, in the same format as `.mcp.json`                        |
| `memory/`                          | [User notes](/memory), as Markdown files you can edit                                  |
| `accounts/claude/<name>/`          | Each extra [account](/models-and-accounts#switch-accounts)'s login                     |
| `plugins/`                         | Your skills, linked so the agent can load them                                         |
| `usage/claude.json`                | Days `/stats` has counted, so it only reads what was added                             |
| `logs/<time>.jsonl`                | A [debug log](/reference/troubleshooting#record-a-debug-log) per `--debug` session                |
| `projects/<project>/settings.json` | The project's [mode](/permission-modes), and its `.mcp.json` servers you turned on     |
| `projects/<project>/permissions.json` | Rules you saved with "don't ask again"                                              |
| `projects/<project>/memory/`       | [Project notes](/memory)                                                               |
| `projects/<project>/sessions/`     | The project's [conversations](/conversations/resume)                                          |

## Back up or move

Copy the folder to keep your conversations, memory and settings. To start fresh, delete it; Jinion creates it again
on the next run. Your Claude login isn't in it, except for accounts you added with `/account`.
